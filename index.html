What is Solace?

Minecraft Earth shut down in 2021 — but we brought it back. Solace is an unofficial server replacement for Minecraft Earth, based on Vienna. Most core gameplay already works, including the map, journal, activity log, inventory, crafting, smelting, boosts, tappables, buildplates, and the store, with features like challenges, seasons, and adventures still under active development. The project is still a work in progress, so expect bugs and breaking changes.

How to Start Playing

1

Set Up the Server

Install the .NET 10.0 SDK and Java 17, then clone the Solace repository and run publish.ps1 -profiles framework-dependent-{os}-{arch} followed by run_launcher.ps1. On Linux, macOS, or Termux you can instead run the one-line install script from the repository.

2

Configure & Start the Server

Open localhost:5000, create an account and confirm the email, then set your PC's IP address under Server Options along with a MapTiler API key (or disable map tile rendering), and click Start under Server Status.

3

Patch the Client

Use MCE Patcher or Project Earth Patcher to patch your Minecraft Earth APK with your server IP.

4

Launch the Game

Install the patched APK on your device and start exploring Minecraft Earth again.

FAQ

What are the requirements?
You need a PC running Windows or Linux, the .NET 10.0 SDK, and Java 17 (JRE or JDK). macOS is untested, and high-end Android devices can run the server via Termux.
What is Solace?
Solace is a replacement server for Minecraft Earth based on Project Vienna. It is not affiliated with, authorized, or endorsed by Microsoft or Mojang Studios. More info at github.com/Earth-Restored/Solace.
App says "Cannot connect to the network"?
Make sure the server is running, check that your PC's IP address is correct, verify your firewall isn't blocking it, and ensure your phone and PC are on the same network.
Where do I download the APK?
You need a legal copy of Minecraft Earth. We do not provide pre-patched APKs — use the MCE Patcher or Project Earth Patcher to patch your own APK.

INSTALL GUIDE

Full setup walkthrough for the server and client

System Requirements

Hardware & OS

  • PC: Windows or Linux — macOS is currently untested.
  • Mobile: High-end Android devices can run the server through Termux.

Software Dependencies

These are installed automatically if you use the semi-automatic install method below.

  • .NET 10.0 SDK
  • Java 17 (JRE or JDK) — newer versions may not work
  • On Linux, PowerShell is needed to run the build script

Find Your PC's IP Address

You'll need this before you start, since both the server config and the client patcher point at it.

Windows

  • Open a terminal, type ipconfig and press enter
  • Look under "Wireless LAN adapter Wi-Fi" (WiFi) or "Ethernet adapter Ethernet" (wired)
  • Note the value next to "IPv4 Address"

Linux

  • Run ip address, hostname -I, or ifconfig -a

It's usually, though not always, formatted like 192.168.XXX.XXX.

Semi-Automatic Install (Linux, macOS, Termux)

Open a terminal and run the matching one-liner, then wait for it to finish.

Linux / macOS

sudo curl -sSl https://raw.githubusercontent.com/Earth-Restored/Solace/main/install.sh | bash

Termux

curl -sSl https://raw.githubusercontent.com/Earth-Restored/Solace/main/install.sh | bash

Once it completes, pick up the Manual instructions below starting at server step 4.

Manual Install — Server

1

Clone the Repository

git clone https://github.com/Earth-Restored/Solace.git

2

Publish the Build

cd into the Solace directory and run publish.ps1 -profiles framework-dependent-{os}-{arch}, swapping {os} for win, linux, or osx, and {arch} for x64, x86, arm64, or arm32 (e.g. framework-dependent-win-x64).

3

Run the Launcher

Run run_launcher.ps1.

4

Create an Account

On the same device, open localhost:5000, register an account, and confirm your email from the page that opens before logging in. If you miss the confirmation step, you'll need to delete the account database and start over — see the project's README.

5

Set Server Options

Under "Server Options," set Network/IPv4 Address to your PC's IP, then either disable Map/Enable Tile Rendering or add a Map/MapTiler API key (get one from your MapTiler account once logged in).

6

Start the Server

Under "Server Status," click Start.

7

Accept the EULA

Accept the Minecraft server's EULA when it's prompted in the launcher's logs.

8

Grab the Resource Pack

Download and move the "resourcepack" file as described in the launcher's logs.

Manual Install — Client

iOS players can try an unofficial patcher, though only the AltStore install method is expected to work reliably. On Android, choose between the two patchers below.

Shop Needs a Microsoft account that played before shutdown Always works with custom login
A

Project Earth Patcher

Download and install the patcher on a device with a legal copy of Minecraft Earth already installed. Open it, go to the 3-dot menu → Settings, and under Locator Server enter http://{ip}:8080 (use your PC's IP or hostname, and keep it as http:// not https://). Go back and start patching, then open the newly patched app to play.

B

MCE Patcher

Download MCE Patcher (the UI build is recommended) or build it from source. Acquire a Minecraft Earth APK, e.g. by dumping it from your phone, then run the patcher and select the APK. Change the locator hostname/IP to {ip}:8080 using your PC's IP or hostname — for non-Microsoft login, adjust the login options accordingly (this is the default in Simple UI mode). Click Patch, move the patched APK to your phone, install it, and you're ready to play.

Launcher Buildplate Preview (Optional)

1

Get the Java Resource Pack

You'll need the Minecraft 1.20.4 resource pack. The easiest way is to pull it straight from the game's JAR: open 1.20.4.jar from your Minecraft install folder in an archive tool like 7-Zip, then navigate to assets/minecraft/.

2

Copy the Assets

Copy every folder from assets/minecraft/ and paste them into staticdata/resourcepacks/java/minecraft/.

3

Enable the Toggle

Turn on "Enable Buildplate Preview in Launcher" under Server Options → Data Handling.
